# 塔奥 thalvior

### 多店铺电商 ERP · 可运行 Demo

一个真实跑起来的多平台多店铺电商 ERP 原型，覆盖「抓单 → 审单 → 锁库存 → 打单 → 发货 → 回写」核心履约闭环。
参考聚水潭、旺店通、万里牛、快麦、吉客云等主流产品的功能与模板体系设计。

## 一、启动（3 步）

```bash
cd erp
pip install -r requirements.txt     # 已装可跳过
python -m backend.seed              # 生成演示数据（12 店铺 / 8 平台 / 20 SKU / 3 仓 / 百余笔订单）
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8801
```

浏览器打开 `http://localhost:8801`，无需 npm、无需联网（React / Ant Design / ECharts 已本地化到 `frontend/vendor`）。

> 前端源码在 `frontend/src/app.jsx`，改完执行 `node frontend/build.js` 重新编译为 `frontend/static/app.js`。
> 不改前端则无需执行。

## 三、八个必看演示

**1）防超卖**
订单履约 →「模拟平台推单」→ 商品 SKU 填 `SKU-1009`、笔数 15、每单 3 件 → 立即审单。
会看到：前几单审单通过并锁定库存，后续订单直接报「库存不足，缺 N 件」并被挂起，绝不超卖。
原理：可用 = 实物 − 锁定 − 预留，锁库在审单通过瞬间于 `BEGIN IMMEDIATE` 事务内完成，任一商品不足整单回滚。

**2）跨仓拆单**
订单池里找订单号以 `SPLIT` 开头的（主仓缺货、分仓有货场景）→ 点「拆单」→ 拆成 2 个子单，各自绑定不同发货仓。

**3）同买家合单**
订单池里买家昵称以「同买家」开头的订单（同一收件人、同一地址）→ 勾选 2~3 笔 →「同买家合单」→ 合并为一个包裹，原单自动作废。

**4）采购到货入库**
采购供应链 → 采购单列表 → 点「收货入库」→ 实物库存增加并生成批次，采购单变已入库。也可从「智能补货建议」一键生成采购单。

**5）波次拣货到验货**
仓储作业 → 拣货波次 → 选发货仓 → 勾选待发货订单 →「生成波次」→「执行拣货」→ 在「波次拣货任务」里点「验货称重」，运费按实重重算。

**6）盘点出损益**
仓储作业 → 盘点 → 点盘点单号看明细 → 改实盘数 → 回列表点「提交盘点」→ 差异件数与损益金额自动生成，实物库存同步调整。

**7）售后全流程**
售后工单 → 新建（选已发货订单）→「同意」→「退货入库」（良品回库存）→「完成退款」。

**8）看真实利润**
财务对账 → 利润核算 → 点「重新核算订单利润」→ 看各店铺收入、成本、平台费、广告分摊、净利率。注意对比「毛利」与「净利」的差距。

## 四、目录结构

```
erp/
├── backend/
│   ├── db.py            SQLAlchemy 引擎与会话
│   ├── models.py        18 张业务表 ORM 定义
│   ├── services.py      核心引擎：库存池/防超卖、审单规则、快递分配、拆合单、模板渲染
│   ├── seed.py          演示数据生成
│   ├── routers/
│   │   ├── catalog.py   平台/店铺/商品/库存/仓库/看板
│   │   ├── order.py     订单池/审单/发货/拆合单/模拟推单/打印
│   │   └── config.py    规则/快递/模板/用户/日志/API
│   └── erp.db           SQLite（首次 seed 生成）
├── frontend/
│   ├── index.html
│   ├── src/app.jsx      React 18 源码
│   ├── static/          app.js（编译产物）+ app.css
│   ├── build.js         JSX → JS 编译（node）
│   └── vendor/          React / antd / echarts / babel（本地化，离线可用）
└── requirements.txt
```

## 五、已知边界

这是**首版核心履约闭环**原型，用于验证业务逻辑与交互，不是生产系统：

- 平台授权为模拟，未接真实开放平台 OAuth
- 未做登录鉴权（角色仅作展示）
- 打印走浏览器 `window.print()`，未接真实面单云打印组件
- 未做登录鉴权（角色仅作展示）
- 打印走浏览器 `window.print()`，未接真实面单云打印组件
- 未接真实平台 OAuth 与快递面单服务
