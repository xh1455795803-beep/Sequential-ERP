# 塔奥 thalvior · 上线部署指南

本系统是一个**纯自包含**的 Web 应用：FastAPI 后端 + 单文件前端（React/antd/ECharts 已本地化，不依赖任何 CDN）。
只要有一台能装 Docker 的服务器（1 核 2G 即可跑通演示），一条命令就能上线。

---

## 方案 A：Docker（推荐，5 分钟）

### 前置条件
- 一台 Linux 服务器（Ubuntu 20.04+ / Debian 11+ / CentOS 8+）
- 已安装 Docker 与 docker compose 插件
- 一个域名，A 记录已解析到该服务器的公网 IP
- 安全组/防火墙放行 **80** 端口（上 HTTPS 再加 **443**）

### 部署

```bash
# 1. 上传整个 erp 目录到服务器（scp / rsync / git clone 均可）
scp -r erp root@你的服务器IP:/root/erp

# 2. 登录服务器执行
ssh root@你的服务器IP
cd /root/erp
chmod +x deploy.sh
./deploy.sh your-domain.com
```

脚本会自动完成：拷贝文件到 `/opt/thalvior` → 写入域名 → 初始化演示数据 → 构建镜像 → 启动 → 健康检查。

完成后访问 `http://your-domain.com`。

### 常用运维命令

```bash
cd /opt/thalvior
docker compose logs -f app      # 看日志
docker compose restart app      # 重启
docker compose down             # 停止
docker compose up -d --build    # 更新代码后重新构建
```

### 数据持久化

数据库落在 `./data/erp.db`（已通过 volume 挂载到容器外）。
**备份只需拷贝这一个文件**；迁移时把它放到新机器的同目录即可，无需导数据。

## 方案 B：不用 Docker（systemd + nginx）

```bash
# 1. 装依赖
sudo apt update && sudo apt install -y python3-venv nginx
cd /opt/thalvior
python3 -m venv venv
./venv/bin/pip install -r requirements.txt

# 2. 初始化数据
./venv/bin/python -m backend.seed

# 3. 配 systemd
sudo cp deploy/thalvior.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now thalvior

# 4. 配 nginx（改其中的 YOUR_DOMAIN）
sudo cp deploy/nginx-standalone.conf /etc/nginx/conf.d/thalvior.conf
sudo sed -i 's/YOUR_DOMAIN/your-domain.com/g' /etc/nginx/conf.d/thalvior.conf
sudo nginx -t && sudo systemctl reload nginx
```

## 上 HTTPS（生产必做）

免费证书用 Let's Encrypt：

```bash
# 先停掉占用 80 的容器（或临时改用 webroot 方式）
sudo certbot certonly --standalone -d your-domain.com

# 证书复制到容器挂载目录
sudo cp /etc/letsencrypt/live/your-domain.com/fullchain.pem /opt/thalvior/deploy/certs/
sudo cp /etc/letsencrypt/live/your-domain.com/privkey.pem   /opt/thalvior/deploy/certs/

# 打开 docker-compose.yml 的 443 端口映射，并取消 deploy/nginx.conf 里 HTTPS 段的注释
cd /opt/thalvior && docker compose up -d --build
```

证书 90 天过期，配个自动续期：`certbot renew --deploy-hook "cd /opt/thalvior && docker compose restart web"`

## 面向真实商用的三项必改

演示版为了"开箱能跑"，做了三处简化。正式对外提供服务前请改掉：

| 项 | 演示现状 | 生产要求 |
|---|---|---|
| **登录鉴权** | 无，任何人打开即可操作 | 接入真实登录，按角色与数据范围做接口级鉴权 |
| **数据库** | SQLite 单文件，2 并发 worker | 换 PostgreSQL/MySQL；SQLite 在并发写入下会锁库 |
| **密钥与配置** | 无敏感配置 | 平台 AppKey/Secret、数据库连接串走环境变量或密钥管理，禁止入库与硬编码 |

另外 `--workers 2` 是按 1 核 2G 给的；CPU 核数多时按 `2 × 核数 + 1` 调整。

## 验证清单

部署完逐条确认：

- [ ] `http://域名/api/health` 返回 `{"status":"ok","product":"塔奥 thalvior"}`
- [ ] 页面左上角显示「塔奥 / thalvior」
- [ ] 13 个页面都能打开，无控制台报错
- [ ] 订单履约页推单能触发防超卖（连续推同一紧缺商品）
- [ ] 财务对账页点「重新核算订单利润」能出数
- [ ] 重启服务器后服务自动恢复（`docker compose` 的 `restart: unless-stopped`）
